**Kivgraph v0.9.6 makes development builds easier to install and keeps
graph-backed searches reliable across agent worktrees.**

- **`scripts/install-dev.sh` installs a checkout safely** by verifying a local
  bundle, replacing only the executable atomically, and restoring the previous
  executable if a supervised daemon restart fails.
- **`kivgraph update --channel stable|dev` selects the update channel** while
  prerelease installations follow the development channel by default.
- **The search gate recognizes wrapped and file-listing searches correctly**
  and can identify a registered repository from a linked Git worktree, avoiding
  unnecessary blocking or missed graph-backed guidance.

No stored graph data changed shape, so `requires_reindex` is false: existing
installations can upgrade without rebuilding their graph.
