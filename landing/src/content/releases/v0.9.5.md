**Kivgraph updates now restart the supervised daemon reliably when profiles are
configured.** The daemon publishes its endpoint at installation scope, where
both lifecycle commands and integrations expect to find it.

- **`kivgraph update` replaces and restarts the supervised daemon** instead of
  leaving the previous release running after an upgrade.
- **`kivgraph mcp install` reaches a profile-backed daemon** without requiring
  `--stdio` or a manually copied endpoint file.
- **Profile graph data remains isolated** while the installation continues to
  use one supervised daemon and one shared control endpoint.

No stored graph data changed shape, so `requires_reindex` is false: existing
installations can upgrade without rebuilding their graph.
