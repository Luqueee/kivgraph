**Kivgraph v0.9.10-dev.1 makes coding-agent setup global, guided, and
semantic-first.**

- **`kivgraph configure` and `kivgraph instructions install` configure the
  selected agent's user-level settings** instead of modifying repository
  instructions. Codex, Claude Code/Desktop, OpenCode, and Oh My Pi use their
  native configuration surfaces.
- **Managed `KIVGRAPH.md` prompts are referenced by an absolute path** for
  Codex, Claude, and Oh My Pi. Existing managed project prompts and relative
  references migrate safely, while customized prompts remain protected by
  `--force`.
- **The installed prompt requires Kivgraph MCP research before exploration
  subagents or semantic text search.** It maps code-research questions to the
  relevant tool, records fallback limits, and requires consent for indexing.

This development release changes agent setup behavior only. It does not change
graph or schema data, so existing installations do not need to rebuild their
graph. Install it explicitly and use `kivgraph update --channel dev` to follow
the development release stream.
