**Kivgraph v0.9.8-dev.1 is a development prerelease for testing managed
daemon refresh during updates.**

- **`kivgraph update` repairs a Kivgraph-managed stale supervisor** when the
  installed unit uses a repairable legacy format, then verifies that the
  restarted supervisor is installed before continuing.
- **The update protects the supervised daemon process** from generic stale
  process cleanup, including when a refresh or endpoint check fails.
- **Public supervisor restart behavior is covered by regression tests** across
  the update and supervisor layers.

This development release changes installed runtime integration behavior, not
graph or schema data, so existing installations do not need to rebuild their
graph. Install it explicitly and use `kivgraph update --channel dev` to follow
the development release stream.
