**Kivgraph reports that it ran.** The first-run ping designed in v0.9.2's
`--introspection` release, and received since by `landing/src/install-report.mjs`,
now has a sender: `serve` and the daemon each report the event the first time a
given version runs on a machine, and `scripts/install.sh` and
`scripts/install.ps1` report a second, independent one when they finish. One
event, five fields, off the command's own path -- a goroutine bounded to two
seconds, every error dropped, so a machine with no network runs identically to
one with it. `KIVGRAPH_TELEMETRY=0` turns both off before anything is written,
and an opted-out machine leaves no local marker either, so opting back in
reports the version actually running rather than nothing. The complete field
list, what is never sent, and the incident that shaped the endpoint's
validation are documented at https://kivgraph.dev/telemetry/.

- **`kivgraph index` indexes the current project without a configured
  registry.** It detects the project's languages and runs a local,
  `.kivgraph`-scoped full rebuild; `kivgraph index --full` keeps its old
  meaning, the explicit rebuild over the configured registry.
- **Uninstalling is a command now, not a manual cleanup.** `scripts/uninstall.sh`
  and `scripts/uninstall.ps1` ship on every release, remove what the installer
  placed, and refuse to touch configuration or graph state they did not create.
- **`mcp install` asks before it provisions a daemon.** A missing or stale
  supervised daemon used to appear silently; installing now prompts for
  consent, and `--daemon` or `--stdio` bypass the prompt explicitly. A busy
  `127.0.0.1:7788` resolves to another loopback port once, and that choice is
  persisted and reused rather than re-resolved on every command.
- **A supervised daemon now carries the PATH of the shell that installed it.**
  Neither systemd nor launchd reads a shell profile, so a unit declaring no
  PATH silently lost a `node` installed through nvm or Homebrew -- every
  TypeScript repository failed to index with nothing in the logs to say why.
  `daemon install` records that shell's PATH on both backends now, and a
  resync that keeps failing stops retrying instead of rebuilding the whole
  corpus every six seconds forever.
- **Every one of the 98 published MCP tool arguments describes itself**,
  including the nested objects of `get_source` and `index_project`. Schema
  description coverage was the cited reason behind a 3.4/5 mean tool score on
  Glama; a test now fails the next argument that ships without one.
- **A session is briefed on the first Kivgraph tool call it makes**, not only
  at skill install. The advisory attaches the call budget through
  `additionalContext` and never refuses a call -- gating the tools themselves
  would put friction on the one behaviour the gate exists to encourage.

Nothing stored changed shape, so `requires_reindex` is false: an existing
installation upgrades without a pass.
