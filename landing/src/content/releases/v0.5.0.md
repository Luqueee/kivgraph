This release introduces an isolated storage format for each workspace, meaning that Kivgraph no longer merges projects into a single file. **You must reindex your projects** (`kivgraph index --full`) after updating.

- Details in `docs/adr/0060-el-receptor-de-un-metodo-es-un-hecho-del-grafo.md` in the repository: why this change was made and how the new storage layout works.
- The previous global index will be ignored, but not deleted automatically.
- Read operations are now up to 14% faster in large mono-repos because cross-repository scopes no longer require filtering out unrelated projects.
