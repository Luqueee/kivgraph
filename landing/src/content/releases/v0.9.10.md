**Kivgraph v0.9.10 makes coding-agent research more visible, safer, and easier
to audit.**

- **`kivgraph configure` installs MCP, skills, hooks, and user-level
  instructions for every selected agent.** `kivgraph instructions install`
  remains available for installing instructions independently. Codex, Claude
  Code/Desktop, OpenCode, and Oh My Pi use their native configuration surfaces,
  with managed prompts referenced by absolute path and existing customized
  prompts preserved unless `--force` is requested.
- **Kivgraph MCP calls now have an explicit visible-use contract.** Agents name
  the tool, target, and purpose before each call; `find_by_intent` includes its
  exact intent. The freshness gate repairs a stale target checkout only through
  approval-gated indexing and never uses a graph from another checkout as
  evidence.
- **`kivgraph logs` now shows bounded, safe query summaries in aligned columns.**
  Opaque keys, consent data, and absolute paths are excluded from the durable
  record, including Windows and UNC paths. A missing symbol is rendered as the
  neutral `NOT_FOUND` result rather than a failed tool call.

This release changes agent setup, MCP guidance, and local operator logs. It
does not change graph or schema data, so existing installations do not need to
rebuild their graph. Install it through the stable channel or run
`kivgraph update --channel stable` to follow stable releases.
