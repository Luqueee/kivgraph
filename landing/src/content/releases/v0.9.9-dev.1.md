**Kivgraph v0.9.9-dev.1 is a development prerelease for keeping graph content
freshness observable while sources change.**

- **`graph_status` reports freshness for the currently published generation**
  and avoids serving stale cached status after source changes.
- **Freshness monitoring covers configured roots, manifests, and build
  configuration files**, including explicit manifests outside project roots.
- **Exclusion matching is consistent** for recursive, absolute, and relative
  patterns, with invalid patterns rejected before monitoring starts.
- **Monitor and publisher lifecycle safeguards** prevent stale state and
  concurrent ownership races during refreshes.

This development release changes monitoring and status behavior, not graph or
schema data, so existing installations do not need to rebuild their graph.
Install it explicitly and use `kivgraph update --channel dev` to follow the
development release stream.
