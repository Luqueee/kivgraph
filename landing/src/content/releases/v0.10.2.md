**Kivgraph v0.10.2 stops a pass nobody asked for from emptying a served graph
when an analyzer is missing, and keeps `go` upgrades from breaking Go loads.**
No schema or stable key changes. A graph from v0.10.1 stays readable; rebuild it
to pick up the reading changes below.

- **A daemon no longer replaces a Rust graph with an empty one.** The guard of
  v0.10.1 only recognised `*_NOT_LOADED` failures. A pass started on a `PATH`
  without `rust-analyzer` reports `ANALYZER_UNAVAILABLE`, slipped through, and
  published a generation with no symbols over one of `4,595`. It now counts as a
  failure to load: the pass names the files it would have lost and the active
  generation stays.
- **`golang.org/x/tools` stays at `0.52`.** Version `0.53` asks the `go` on the
  `PATH` which standard library to type-check against, in a mode that ignores
  `GOTOOLCHAIN`. With a `go` newer than this build, every Go module failed to
  load. Dependabot no longer proposes it; ADR 0149 says why.
- **A compact answer keeps one line of a failure's detail.** The `detail` of a
  scope or a failed reference is its first line, at most `320` bytes, and the
  block says `"details":"view=full"` when it cut something. A module that did not
  load had put `4.4 KB` of compiler output in an answer about one name.
- **A compact `completeness` block groups what it repeats.** Invisible scopes
  and blind spots that differ only in the package or the place are one row with
  `packages`, `occurrences` or `at`. `find_references` on a common name is about
  half the size; `view: "full"` is byte-identical to before.
- **Indexing consent is a question the server returns.** `index_project` and
  `start_index_project` answer with an input request bound to the batch, as
  protocol `2026-07-28` requires, instead of asking mid-request (ADR 0158).
- **Paths that are not part of the repository are left out in more places.**
  Workspace modules, the freshness inventory, the watcher and the source
  observation all skip a directory that is another Git checkout, so a nested
  clone no longer reads as a change. A `GOTOOLCHAIN` saved with `go env -w` is
  left alone, a profile has its own Go work file, and a TypeScript dependency
  keeps its alternate resolutions.
- **`daemon install` refuses a `HOME` that is not the account's**, so a test or a
  script cannot register the real launchd unit. `--allow-foreign-home` opts in.
- **The search gate reads through wrappers and redirections.** `time`, `timeout`,
  `nice`, `nohup`, `env`, `command`, `exec`, `sh -c` and a subshell no longer hide
  a search, and the target of a redirection is not read as a file.
- **`kivgraph update` refuses an archive entry outside its directory.**
- **Dependencies.** go-sdk `1.8`, `@xyflow/react` `13`, `vitest` `5`, TypeScript
  `6` in the landing, and the groups of Go, worker, web and landing updates. The
  viewer stays on `three` `0.184`.

**To move to this release:** run `kivgraph index --full` after updating. If you
run the daemon, restart it so it serves with the new guard; a client that calls
`index_project` must handle an input request in place of a prompt.
