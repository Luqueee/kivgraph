**Kivgraph v0.9.9 adds guided setup for coding agents and improves MCP
consent compatibility.**

- **`kivgraph configure` now guides first-run setup** for Codex, Claude Code,
  Claude Desktop, OpenCode and Oh My Pi. It can configure MCP, the Kivgraph
  skill, hooks, the supervised daemon and project instructions from one
  command.
- **Agent instructions can be installed explicitly** with
  `kivgraph instructions install`. The command writes the native
  `AGENTS.md`, `CLAUDE.md` or `.omp/AGENTS.md` destination for the selected
  client and preserves existing project instructions.
- **The installers offer guided configuration after a successful install.**
  `KIVGRAPH_CONFIGURE=0` skips the offer, while `KIVGRAPH_CONFIGURE=1`
  accepts it when an interactive terminal is available. A non-interactive
  install remains successful and prints the command to run later.
- **Codex MCP consent uses native tool approval together with
  `confirmed: true`**, while URL-only MCP clients use the explicit
  confirmation fallback and clients supporting form elicitation retain the
  interactive server prompt.

This release changes client setup and MCP consent handling only. It does not
change graph or schema data, so existing installations do not need to rebuild
their graph. Install it through the stable channel or run
`kivgraph update --channel stable` to follow the stable release stream.
