**Kivgraph v0.10.3 lets a workspace with one unsupported module be indexed, and
makes a repeated pass on a large workspace lighter.** No schema or stable key
changes. A graph from v0.10.2 stays valid, so there is nothing to rebuild.

- **A module above the language ceiling no longer fails the whole pass.** A Go
  module that requires a newer `go` than this build type-checks with used to
  refuse the entire workspace. It is now declared as `MODULE_NOT_LOADED`, naming
  the version it requires and the one this build supports, and the other modules
  are indexed. `doctor` still reports `toolchain.typecheck` as a failure and
  names the modules (ADR 0147).
- **A repeated pass peaks about `28%` lower.** The pass let go of the facts it
  had just loaded into the database but kept them in memory until it finished.
  On a workspace of `60` repositories and `553,000` symbols the peak physical
  footprint went from `7.6 GB` to `5.5 GB`, with the same graph digest. Writing
  the canonical tables one at a time trims a few percent more.
- **The fact cache is binary and four times smaller.** Entries are stored in a
  compact format keyed to the shape of the facts instead of JSON: `1.5 GB`
  became `367 MB` on that workspace, and a warm pass spends about `7 s` less CPU.
  Entries from v0.10.2 are removed and read again on the first pass, so that
  pass is as slow as a cold one; a cold pass is not faster (ADR 0159).
- **Frozen third-party corpora for the token benchmark.** `cobra`, `ky` and
  `ripgrep` are pinned to commits and a ratchet checks that a change does not
  raise the cost of an answer or lose references. It runs in CI and does not
  change the binary.
