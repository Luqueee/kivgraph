**Kivgraph v0.10.0 answers which types implement a declaration and what a diff
reaches, indexes in the background, and corrects answers that were wrong.** The
canonical schema moves to version `5`, so an existing graph has to be rebuilt.

- **`find_implementations` answers which types implement or override a
  declaration.** It reads `IMPLEMENTS` and `OVERRIDES` edges; TypeScript now
  resolves implementations through the compiler. This changes the canonical
  schema to version `5`.
- **`kivgraph impact --base REF` shows what a diff reaches.** It maps the lines
  that differ from `REF` onto the symbols that hold them, follows who depends
  on those in one traversal -- the same edges, bounds and withheld kinds as
  `get_blast_radius` -- and lists the affected tests apart (`by_test_file` with
  `--json`). A graph older than the working tree refuses to answer, because the
  changed lines would land on the wrong symbols: run `kivgraph index` first, or
  pass `--allow-stale`. Tests are recognised by path convention.
- **Indexing can run in the background.** `start_index_project` returns at
  once and `get_index_status` reports progress, for clients that cut a tool
  call off before a full rebuild finishes.
- **Answers that were wrong are corrected.** `get_source` no longer returns
  another repository's file when two repositories share a relative path, and
  no longer drops a symbol no profile holds without saying so.
  `get_blast_radius` and `trace_dependencies` answer `LOWER_BOUND`, not
  `COMPLETE`, when `max_nodes` cut the walk. A cursor is bound to
  `include_derived`. A selector's `path` names a file or a directory instead of
  a string prefix. `find_by_intent` spends its candidate bound inside the
  narrowing you gave it and on the rarest term first.
- **Tests are read by default, in every language that has the setting.** Go,
  Dart, Java, C# and Python now index their test files, so a use from a test
  is a use. On real repositories that is most of what was missing: reading
  tests takes file recall from `61.1 %` to `100 %` on a Java library and from
  `65.9 %` to `100 %` on a Go one. `find_references`, `find_implementations`,
  `trace_dependencies`, `get_blast_radius` and `find_cross_repo_consumers` take
  `exclude_tests` to leave them out of an answer. A `config.yaml` that spells
  `include_tests: false` out keeps it. Indexing reads more: on `prometheus` the
  peak goes from `5.5` to `6.6 GB`; serving costs at most `35 MB` more.
- **References that were missed are found.** Measured against each language's
  own compiler or analyzer on real repositories, and fixed where the graph fell
  short: a Go use inside a local `var` or `type`, TypeScript private names and
  the keys of a literal passed to a generic call, Dart references the analysis
  server navigates, names inside Rust macro bodies (as candidates), Java and
  C# occurrences the SCIP reader dropped, and Python imports of a package by
  its own name, re-exports and `module.member`. The syntactic Python worker now
  records every member access it cannot resolve, so its answers say
  `LOWER_BOUND` where they used to say `COMPLETE` and miss a file.
- **A failure bounds answers only in its own language.** An unresolved
  `Command` in a Rust file no longer turns `find_references` for a Go `Command`
  into `LOWER_BOUND`.
- **One repository that cannot be read no longer ends the pass.** A C#
  repository with no solution, a Java build that fails, a Python producer that
  exits, a `tsconfig.json` that does not parse or a TypeScript package the
  worker fails on used to leave every repository without a graph. The pass now
  indexes the rest, exits `0`, and names what it left out on an
  `index.<language>.not_read` line; answers about it say `LOWER_BOUND`.
  `kivgraph init --languages go,typescript` over a Go repository no longer
  fails the index either.
- **`exclusions` mean the same in every language.** Java, C# and Python
  ignored the key; Dart read a bare name at any depth. All of them now use the
  registry's matcher, where a bare name is root-only and `**/name` matches at
  any depth.
- **An indexer's processes do not outlive it.** A Java, C#, Python or Dart
  tool whose parent was killed or cancelled stayed running; on macOS and Linux
  its whole process tree is now ended with the pass.
- **No daemon is installed under a home that is not the account's.** `serve`,
  `mcp install` and `configure` run under a throwaway `HOME` registered a
  supervised daemon that started against another installation. They now serve
  or write the stdio entry and say why; an explicit `--daemon` is refused.
- **A Go index holds less memory.** Dependencies are loaded without their
  function bodies and the pass collects garbage earlier and stays under a
  container's memory limit.
- **The viewer is closed to the network by default.** `kivgraph ui` binds
  `127.0.0.1:7777` and answers `403` to a request whose `Host` is not this
  machine. A configuration that already says `0.0.0.0:7777` keeps working and
  keeps warning; there is still no authentication.
- **Indexing no longer hangs or drifts.** A Java or C# pass that failed while
  extracting its scratch tree waited forever; that tree now also follows staged
  renames, new directories and edits under directories named like build
  output. Repositories registered after a server started are watched. One
  unreadable source file no longer stops the watcher. An edit that lands while
  a pass is finishing keeps the profile stale instead of being forgotten.
  Reading a repository no longer rewrites its `.git/index`.
- **Indexing reads what the language tools read.** Go packages follow the `go`
  tool's rules: `testdata` and directories beginning with `_` or `.` are left
  out, a directory that is not one package no longer stops the index, a
  malformed `go.mod` under those directories is skipped, and the test main that
  `go test` generates is no longer published. A monorepo root that holds only a
  base `tsconfig` no longer claims its packages' files, and the files a package
  leaves out of its `include` are now indexed when
  `typescript.include_unclaimed_sources` is on. The TypeScript worker publishes
  no symbol of the compiler's default library, which used to make a repository
  that holds its own copy of TypeScript alternate between two symbol counts. A
  Dart repository depends on the repositories its package config reaches, and
  `dart.include_external_packages: true` no longer fails the whole pass.
  Directories a tool tags as caches (`CACHEDIR.TAG`) are skipped in every
  walk, and `kivgraph doctor` lists them.
- **Toolchains are never installed behind your back.** A Rust pass no longer
  lets a probe or an offline run install `rust-src` or a toolchain, and a
  `rust-toolchain` file is tracked as a source.
- **A second index is cheaper and honest about why it is not.** The fact cache
  now notices a change of the TypeScript engine and worker modules, the Dart
  SDK, and the Rust toolchain, keeps only the newest entries of each unit, asks
  the toolchains once and in parallel, and names the part of the analyzer that
  moved when it refuses entries (`analyzer_changed=rust:34`). Source
  verification can use a `stat` signature with
  `indexing.source_verification: signature`; the default stays a full digest.
- **Storage and updates are safer.** `rollback`, `clean` and pruning take the
  same lock as a rebuild, so a rollback is refused during one instead of being
  undone by it, and `rollback` now says that running servers keep the previous
  generation until they restart. The fact cache prunes only its own files and
  counts a hit as a use. A second `kivgraph daemon` no longer hides the one
  already running. `kivgraph update` no longer reports a failure after
  installing.
- **A published graph no longer reads freed memory.** A reader that kept a
  string table after a publish replaced its snapshot could read the file's
  mapping after it was released; the mapping now lives as long as anything that
  came from it. On a filesystem that cannot preallocate (NFS before 4.2, 9p,
  FUSE) the space reserve is written instead of failing, so the store opens.
- **Daemons and agent hooks behave.** On Linux, `kivgraph daemon install` over
  a running unit restarts it, so the new binary, arguments and `PATH` take
  effect. The OpenCode plugin no longer kills its host when the gate exits
  before reading its input. A refusal of a native `Grep`, `Glob` or subagent
  call says how to insist when there is no command to prefix.
- **Four configuration keys are retired.** `mcp.default_limit`,
  `mcp.maximum_limit`, `mcp.maximum_depth` and `mcp.maximum_visited_nodes` were
  validated and documented and nothing read them. A configuration that carries
  them still loads; `kivgraph doctor` names them as safe to delete.
- **Dependencies are patched.** OpenTelemetry for Go moves to `1.47.0`, and the
  landing site (`astro` `7.4`), the viewer's tooling and the worker's test
  tooling are past their open advisories.

**To move to this release:** the schema, the TypeScript default-library change
and the tests now read by default mean an existing graph has to be rebuilt, so
run `kivgraph index --full` after updating. A pass that used to fail on one
unreadable repository now exits `0`: read the `not_read` lines.
