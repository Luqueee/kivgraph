**Kivgraph v0.9.7 keeps every installed runtime integration in sync after an
update.**

- **`kivgraph update` refreshes the installed supervised daemon** after
  replacing the bundle, so open chats continue reaching the new daemon without
  a manual reinstall.
- **The update refreshes Kivgraph-managed hooks, skills, and MCP registrations**
  while preserving user-owned configuration, project-scoped entries, and
  unrelated integrations.
- **Endpoint migrations require durable Kivgraph ownership evidence**, avoiding
  accidental replacement of ambiguous user configurations.

The update-runtime tests cover supervised daemon restart and owned hook, skill,
and MCP refresh. The integration migration tests cover endpoint ownership and
token replacement. The release validation passes `go test ./... -count=1`,
`make test-ladybug`, and `make landing-check`.

This release changes installed runtime integrations, not graph or schema data,
so existing installations can upgrade without rebuilding their graph.
