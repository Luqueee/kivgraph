**Kivgraph can serve multiple graph profiles from one server.** A profile keeps
its own configuration, graph state, and indexing lock while sharing the server
process, making it practical to work with several projects without running a
separate daemon for each one.

- **Profile-aware MCP tools and CLI commands** select the requested graph while
  preserving the existing single-profile configuration and commands.
- **The local `index` workflow is more reliable for project-local Go modules.**
  Synthetic workspace paths now remain stable across project indexing runs.
- **Oh My Pi can install Kivgraph's tool-use hook** alongside the existing agent
  integrations, including the first-call guidance and session-scoped budget
  advisory.
- **MCP tool responses and project status are profile-aware**, so callers can
  identify which graph answered a request and distinguish unavailable profiles
  from empty graphs.

Nothing stored changed shape, so `requires_reindex` is false: existing
installations can upgrade without rebuilding their graph.
