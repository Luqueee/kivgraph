**Kivgraph v0.10.4 lets an agent open the code behind a reference in one call,
and resolves Rust methods by their type.** No schema or stable key changes. A
graph from v0.10.3 stays valid, so there is nothing to rebuild.

- **`get_source` opens the callable at a position.** Pass `repository`, `path`,
  `line` and the `publication` token from the same single-profile
  `find_references` response, and it returns the innermost indexed callable that
  contains that line. The token identifies the published graph, so a rebuilt
  graph that reuses a generation number is refused instead of answering with a
  stale line. The file must still match its indexed digest (ADR 0161, ADR 0164).
- **`find_references` can bring the callers' code with it.** `include_evidence`
  adds bounded previews for the first five distinct exact callers and the
  subject's own declaration, each verified against the indexed digest and
  marked `unavailable` with a reason when it cannot be. Ordinary replies do not
  carry the `publication` token, so their cost does not move (ADR 0162).
- **Rust methods resolve by their type.** A name such as `LineStep::next_impl`
  now resolves through the analyzer's `METHOD_OF` edge, including associated
  functions, raw identifiers and Unicode names. An unproven receiver is offered
  as a bounded, labelled suggestion and never selected. `name` next to
  `qualified_name` is a check, not a second lookup (ADR 0160, ADR 0163).
- **A qualified name resolves to its declaration.** It no longer lands on an
  export or a re-export that mentions the name.
- **Published snapshot proof now covers file hashes.** The recorded digest of a
  generation includes each file's content hash and lives in
  `snapshot.content.v2.sha256`. A generation published by v0.10.3 has no such
  record, so its first load derives the snapshot from the stored graph, as it did
  before the file existed. The next `index --full` writes the new record. Answers
  are unchanged; only that first load costs more (ADR 0165).
- **A parser fix.** `golang.org/x/text` moves to v0.39.0.
- **The paired agent trials are published.** The benchmark reports compare
  `grep` and `read` with the graph tools on matched questions. They record that
  the tools were not faster in every session, and they do not change the binary.
