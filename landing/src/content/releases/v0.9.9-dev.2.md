**Kivgraph v0.9.9-dev.2 improves `index_project` consent compatibility in
Codex Desktop.**

- **Codex uses its native tool approval together with `confirmed: true`**, so
  indexing no longer depends on a server-side form elicitation that Codex
  cannot answer.
- **URL-only MCP clients use the explicit confirmation fallback**, while
  clients that support form elicitation keep the interactive server prompt.
- **The Codex setup guidance documents** `approval_mode = "prompt"` for
  `index_project`.

This release changes MCP consent handling only. It does not change graph or
schema data, so existing installations do not need to rebuild their graph.
Install it explicitly and use `kivgraph update --channel dev` to follow the
development release stream.
