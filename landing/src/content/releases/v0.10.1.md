**Kivgraph v0.10.1 closes the places where an answer said `COMPLETE` over
code nobody had read, and makes every command refuse before it writes.** No
schema or stable key changes; the loaders read more, so an existing graph has
to be rebuilt to gain it.

- **A TypeScript package with no `tsconfig.json` is indexed.** A package that
  ships its source and declares no project was read by nobody. It is read now
  through a project written for the pass, outside the repository, and `index`
  names it on `index.typescript.inferred`. A file in no package at all is
  named on `index.typescript.unclaimed_not_read`.
- **An import of a package of the same repository is an edge.** In a
  workspace whose packages publish source, `import { api } from "@scope/client"`
  produced nothing, with or without a project, and `find_references` answered
  `COMPLETE` with none of the importers. On one monorepo an export every page
  imports went from no symbol to `29` files.
- **Files an analyzer does not read are declared, not ignored.** An `.astro`,
  `.vue` or `.svelte` file that writes an exported name
  (`COMPONENT_FILE_NOT_READ`), and a Rust file the build configuration left
  out (`TARGET_NOT_BUILDABLE`), make the answer about that name `LOWER_BOUND`
  with the file listed. A source such a scan cannot open is declared for its
  package or crate. Component files are watched: editing one makes the graph
  stale, and a cached pass reads it again.
- **Top-level Rust uses have an owner.** A use no declaration contains -- the
  body of a fuzz target, which is one macro call -- belongs to the scope of
  its file, as it already did in Go and TypeScript. It was counted and
  dropped.
- **References that were missed are found.** A write through a TypeScript
  `set` accessor, a destructured `await import()`, a Dart
  `Extension(receiver).member`, a Rust use of a crate that another Cargo
  workspace of the same repository declares, and `${configDir}` in an
  inherited `tsconfig.json`.
- **Exclusions hold inside a package that is loaded.** A Go file an exclusion
  names still published its facts when the rest of its package was read; the
  scan of Rust files the build left out declared files the repository
  excludes; an `include` glob and the Dart walk entered directories every
  other walk skips.
- **`find_implementations` lists subclasses.** It reads `EXTENDS` beside
  `IMPLEMENTS` and `OVERRIDES`.
- **A failure bounds only the answers it could change.** Incomplete
  implementation relations (`IMPLEMENTATION_COVERAGE_PARTIAL`) bound
  `find_implementations`, the two walks and the uses of a class, a type or a
  member -- no longer who calls a function, `find_symbol` or
  `get_file_outline`. A bare name resolves whatever declares it, including
  kinds no list names.
- **Dart records far fewer failures.** A use of a parameter or a local is not
  one, and a library nobody registered is recorded once for each declaration
  that uses it, named as an import names it. `217689` failures on one
  application are `47187`.
- **Java is indexed from every build.** With no build at the repository root,
  the outermost build of each branch is run and the indexes are merged.
- **A commit that breaks a module does not empty a served graph.** A pass the
  daemon starts on its own publishes nothing when files the active generation
  reads were not loaded; the generation stays and the daemon says so once. A
  pass you ask for publishes as before. `index --full --unattended` is that
  mode.
- **What Git ignores is not indexed.** A path Git ignores that holds source
  -- generated types, a build that copies `src` -- is an exclusion, listed by
  `kivgraph doctor` on `walk.ignored`. Set `include_git_ignored: true` on the
  registry entry to keep it. Another Git checkout below a repository, a clone
  or a linked worktree, is skipped the same way (`walk.checkout`) and can be
  registered beside its parent. A submodule, which the repository lists in
  `.gitmodules`, is read with it. A repository whose `git ls-files` fails is
  not registered, and is named.
- **Commands refuse before they write.** `init` reads every `--repository`
  first, and `kivgraph index` asks whether the directory can be registered
  before it creates `.kivgraph/`. `start_index_project` refuses a project that
  could never be indexed before it hands out an operation.
- **One registry entry that cannot be opened no longer costs the rest.**
  `index --full`, the watcher, the daemon and `doctor repositories` name it
  (`index.repository.not_read`) and serve the others.
- **`index` says what it did not read.** One `index.audit` line when
  `doctor repositories` has findings, `not read: 70 .swift` for languages no
  loader reads, and a repeated analyzer log line once with a count.
- **Go loads run as the toolchain this build type-checks.** With a newer `go`
  installed, a load sets `GOTOOLCHAIN` to the toolchain the binary was built
  with; `doctor` reports it on `toolchain.go`.
- **`impact` follows a linked worktree** to the registered repository that
  shares its Git directory, with a warning that the trees may differ.
- **The viewer needs no network.** Captions are drawn by the browser, so a
  blocked CDN no longer leaves the canvas empty, and every response carries a
  content security policy. The topology map fits its nodes on load.
- **The search gate looks where the search looks.** It reads `--include`,
  `-g`, `--glob` and `-t` of a shell command, lets an ambiguous name through
  when the searched repository does not declare it, and can read the graph of
  a project indexed with `kivgraph index`.
- **Smaller fixes.** A Cargo workspace left out as shadowed no longer makes
  its crates ambiguous. A fresh installation keeps no `pre-profiles` recovery
  point. The Python worker does not open a named pipe called `x.py`. Java and
  C# build directories of the same name no longer share one location. The
  TypeScript worker reports a failure to close its output.
- **The TypeScript worker uses less memory.** It writes its facts a slice at a
  time: on a program of `2760` files its peak goes from `5.9` to `3.7 GB`.
- **`kivgraph profile`, `mcp`, `hook`, `skill` and `toolchain`** list their
  commands and exit `0`.

**To move to this release:** run `kivgraph index --full` after updating. Two
things change what a pass reads without being asked: paths Git ignores are
left out, and packages with no project are read. Read the `walk.ignored` line
of `kivgraph doctor` and the `index.typescript.inferred` lines of the pass.
A repository that holds component files reads as changed until that pass.
